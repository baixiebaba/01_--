Tagetik 数据模型中央库

抽象
中央库表

抽象

本文档将描述包含在 Tagetik 中央库中的数据表。
当字段以“COD_”开头时，请记住它代表维度的代码；例如，COD_UTENTE 是用户的代码（而不是其描述）。
当某个字段以“FLAG_”开头时，请记住其值为 0 或 1。

中央库表

数据库
Table name: REP_DB
管理数据库的要素表。Tagetik 的单个安装包括：
  • 一个单一的集中式中央库数据库，可在该数据库中管理用户及其角色（用户可以在 Tagetik 中执行的活动）
  • 用于存储数据和数据模型维度以及管理应用程序进程的一个或多个应用程序数据库。

Column Name Data Type Mandatory Comment PK Parent Table Name
COD_DB varchar(50) Yes 唯一的数据库标识符。系统使用数据库的相同唯一标识符代码自动引用中央库数据库 [!]。无法将其删除。

必填字段。它必须与“数据库连接状态”中记录的代码一致，可以从位于主页下半部分的用户菜单中的“信息”菜单中访问该代码。
 Yes
DESC_DB varchar(200) No 数据库描述。 No
COD_DB_APPOGGIO varchar(50) No 源引用数据库的代码。对于用户设置自己环境的标准环境，或者当两个环境可用且用户希望将数据从一个部分复制到另一个部分时，它非常有用
 No
DESC_DB_APPOGGIO varchar(200) No 源引用数据库的描述。
 No

角色
Table name: REP_RUOLO
Tagetik 提供了一些预定义的角色，这些角色基本上涵盖了向不同用户分配角色的大多数情况。用户不能修改或删除其定义。

如果需要定义不同于系统角色期望的活动，Tagetik 将允许用户定义自定义角色。
Column Name Data Type Mandatory Comment PK Parent Table Name
COD_RUOLO varchar(30) Yes 角色的唯一标识符。

对于系统角色：每个系统角色都由带有 $ 字符前缀的代码标识。

对于自定义角色：必填字段。代码的第一个字符不能是 $，因为这是保留的系统角色。在 Tagetik 中，有效字符是介于 33 到 126 之间的 ASCII 代码，但不包括以下字符：61、124、44、39、96、34、47、92、58、42、63、60 和 62。有关 Tagetik 中有效字符的详细信息，请从主页中通过问号图标“？”来查阅用户手册。
 Yes
DESC_RUOLO varchar(200) No 角色描述
 No
FLAG_BASE numeric(1) No 0=对于自定义角色
 No
