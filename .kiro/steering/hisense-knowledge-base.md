## 应收应付（AR/AP）重点口径

- AR/AP 涉及 SAP 公司代码 `S600/S610/S700/S800/S810/S900`，常见源表包括 `BSID`、`BSAD`、`BSIK`、`BSAK`、`KNA1`、`LFA1` 等镜像表，以及账龄、汇率、税率、客商映射等规则配置表。
- DWD 重点对象包括：
  - `dwd_fi_mr_ar_cterm_md`：客户账期明细表
  - `dwd_fi_mr_ar_imocc_mi`：国际营销应收占用明细表
  - `dwd_fi_mr_arap_detail_mi`：往来账龄明细表
  - `dwd_fi_mr_arap_sms_balance_mi`：往来账龄期末余额表
  - `dwd_fi_mr_arap_sum_mi`：往来账龄汇总表
- AR/AP 经分二期链路通常按 `ODS → DWD → DWM（ARPM01~05）→ DWS → ADS` 理解；DWM 重点包含账龄底稿、账龄结果、周转/占用和坏账相关加工。
- 账龄、坏账、周转及影响因素应优先从设计文档的 STEP、规则配置表和现有程序共同核对，不能仅凭字段名称推断。
- 账龄计算、账龄段、坏账计提、科目、客商、利润中心及组织等规则应视为配置驱动逻辑；修改 SQL 前先确认对应规则表和有效期字段。
- `dwd_fi_mr_arap_sum_mi` 与 `dwd_fi_mr_ar_imocc_mi` 并非结构完全一致；知识库记录的实际情况为 sum 约 87 字段、imocc 约 42 字段、公共字段约 25 个，不应强行按同结构处理。
- 知识库记录了设计目录与新版 ARPM 编号之间的待确认冲突，以及部分 SQL 头部缺少用途/源表声明的缺口。遇到相关链路时，应明确标记“待确认”，不可把推导结果当成已确认事实。
- 通用客商维度位于 DIM 层，重点表包括：
  - `dim.dim_fi_mr_cus_mkt_mode_mdg_dd`
  - `dim.dim_fi_mr_customer_dd`
  - `dim.dim_fi_mr_customer_map_dd`
  当前部分中文表名、字段类型及可空性来自推导或尚待补齐，使用时应以项目 DDL/用户最新资料复核。
